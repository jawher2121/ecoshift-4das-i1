# Frontend workspace

The team will build one shared web client. It will call business APIs through Spring Cloud Gateway and sign users in with Keycloak. The planned screens are organizer requests, coordinator review and shortages, and stockroom pickup, returns, and recovery tasks.

The frontend technology choice and starter will be agreed by the team. See the [technical design](../Documentation/EcoShift-Technical-Design.docx) for the routes and access rules.
